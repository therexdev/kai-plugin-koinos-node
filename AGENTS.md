Never import external/cold account private keys, overwrite existing destination keys/wallets, move funds, or start production automatically. New migrations retain original files; interrupted legacy moves preserve their recorded semantics. Preserve unreadable wallet/funding journals and never silently overwrite them. Financial actions keep password proof, native review, exact payload/identity checks and operation cancellation. Never commit publisher private keys.
