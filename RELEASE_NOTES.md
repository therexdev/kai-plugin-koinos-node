Initial signed Koinos Node plugin for KAI Core 0.3.0 or later.

- Reuse saved Mainnet/Harbinger settings and node data directories.
- Inspect Docker prerequisites, service status and bounded redacted logs after native approval.
- Start a sync node or explicitly resume a saved block producer, with verified configuration backups.
- Stop nodes started here when the plugin closes or Local-Only is selected; never auto-adopt existing running stacks.
- Open official Docker install instructions, enable WSL on Windows, and launch an installed Docker Desktop with native review.

No wallet/key access, financial transactions, reward automation, background recovery, quick sync or data relocation is enabled. Docker installation is completed through the official guide; it is not silently downloaded or run by the plugin.
